# Judging criteria → evidence map

Where a judge can verify each typical criterion in minutes, without trusting prose.

## Technological implementation

- **Real agent runtime, not a wrapper**: `src/core/agent/loop/agent.ts` — AI SDK
  `ToolLoopAgent` with typed call options, `prepareStep` compaction, custom stop
  conditions, tool-call repair. 236 unit tests + 13 evaluation tests (`pnpm test`,
  `pnpm evaluate:memory`).
- **Verified-outcome learning**: `src/core/agent/verify/` (evidence deltas; uncertain ≠
  success) → `src/core/memory/` (ledger → gate → typed memory → retrieval → skills).
- **Honest measurement**: every published number is regenerated by
  `pnpm evaluate:memory`; the live harness (`scripts/live-eval.mjs`) drives the real
  extension through a genuine browser restart.

## Use of Qwen / Alibaba Cloud

- `src/core/providers/defs/qwen.ts` — DashScope OpenAI-compatible endpoint; chat + tool
  calls (`qwen-plus`/`qwen3-max`), background extraction routed to `qwen-flash`
  (`src/core/providers/extraction.ts`), retrieval embeddings via `text-embedding-v4`
  (`src/core/providers/embeddings/cloud.ts` on AI SDK `embedMany`).
- Demo portals deploy to **Alibaba OSS**: `deploy/alibaba/deploy.sh`,
  `docs/deployment/alibaba-cloud.md`.

## Quality / originality of the idea

- Memory that is *earned from verified outcomes* with provenance, temporal validity, and a
  deterministic write gate — contrasted with transcript-stuffing approaches in
  `docs/memory-agent/showcase.md` ("beyond OpenClaw-style memory").
- Skills as versioned, shadow-tested, degradable workflows: `src/core/memory/skills/`.

## Design / UX

- Transparent agency: live trace, "Using memory" chips, Memory Center with blocked-attempt
  auditing and per-memory provenance (`src/ui/features/memory/`).
- Confirmation UX driven by a deterministic risk gate, not model politeness
  (`src/core/policy/`, `docs/05-security.md`).

## Potential impact / completeness

- Serverless and local-first: nothing to host, nothing exfiltrated — every browser user is
  the addressable market; BYOK keeps cost with the user.
- Measured outcome deltas (6→3→3 actions; 3→2→1 planning calls; 0% injection success):
  `docs/memory-agent/evaluation-results.md`.
- Security posture audited and documented: `docs/memory-agent/security.md` residual-
  limitations section is honest about what remains.
