Typed memory with a deterministic write gate and a visible Memory Center. Memories carry scope,
provenance, confidence, sensitivity, and temporal validity; the model can propose but never
commit — secrets are discarded (never stored), page-derived content is quarantined, inferred
preferences wait for user confirmation, duplicates reinforce instead of duplicating, and
conflicting facts are superseded with full history. The new Memory tab in settings shows
everything Inquiso knows (including blocked write attempts and per-run task metrics) with
edit / confirm / mark-incorrect / forget / clear / export controls. The legacy remember/recall
KV migrates through the same gate.
