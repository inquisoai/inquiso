Browser skill engine: repeated verified tasks become learned, versioned workflows. A goal that
keeps succeeding mints a shadow skill from its verified trajectory (semantic locators, typed
values always as `{{parameters}}` — never remembered literals). Shadow skills advise the
planner and earn promotion only when independent runs agree with them; verified/trusted skills
execute step-by-step through the exact same confirmation gate and outcome verifier as model
actions (`runSkill` tool). Failures degrade a skill instead of retrying forever; a later
successful run repairs it into a new shadow version with the old one preserved. The Memory
Center's Workflows view shows steps, reliability, and repair history with Trust/Retire
controls.
